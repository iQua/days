---
title: CLI
description: User-facing command-line entry points and retained validation binaries.
---

User-facing entry points are:

- `days` (package `days-legacy`): run one legacy Nexosim TOML scenario.
- `t20f_frontier` (package `days`): run an exact Scalar or compiled device
  backend and emit a complete-state fingerprint.
- `leanguard-run`: generate/discover legacy traces and invoke Lean checkers.
- `leanguard-testgen`: generate, replay, and minimize checker corpora.

The root package also retains campaign and gate binaries:
`t13d_real_image_gate`, `t14_metal_gate`, `t15a_round_benchmark`,
`t15e_sustained_benchmark`, `t16_cuda_gate`, `t17c_cuda_geometry`,
`t17c_wide_corpus`, `t20a_round_timing`, and `t20b3_queue_bytes`. These are
validation surfaces, not a stable general-purpose CLI.
