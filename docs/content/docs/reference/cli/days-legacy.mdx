title: days-legacy
description: Run a Legacy Days simulation from a single TOML configuration file.
---

**Scope: Legacy Days.** The `days-legacy` binary (built from `legacy/src/main.rs`) runs a Nexosim
simulation described by one TOML configuration file. It does not run the Days AGO Scalar, CPU,
Metal, or CUDA engines; use [`days`](/docs/reference/cli/days) for those.

## Usage

```bash
RUST_LOG=info cargo run --release -p days-legacy --bin days-legacy -- <path/to/config.toml>
```

Examples:

```bash
# Minimal example
RUST_LOG=info cargo run --release -p days-legacy --bin days-legacy -- configs/simple.toml

# TCP example
RUST_LOG=info cargo run --release -p days-legacy --bin days-legacy -- configs/tcp_simple.toml
```

## Arguments

- **`<path/to/config.toml>`** (required): path to the configuration file.

If you do not pass exactly one argument, the binary panics with a usage message. A configuration
that fails validation prints `Simulation failed: <reason>` and exits with status 1. Build with the legacy Cargo
features (`l2`, `l2_pfc`, `dcqcn`, `lean`) listed on the [Legacy Days](/docs/legacy#cargo-features)
page to enable those models.

## Logging

`days-legacy` uses `RUST_LOG` for runtime logging.

- Default level if unset: `info`
- Increase verbosity: `RUST_LOG=debug ...`
