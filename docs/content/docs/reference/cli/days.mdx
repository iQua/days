title: days
description: Run a simulation from a single TOML configuration file.
---

The legacy-only binary (built from `legacy/src/main.rs`) runs a Nexosim
simulation described by one TOML configuration file. It does not select the
exact Scalar, CPU, Metal, or CUDA executor; use the root examples or
[`t20f_frontier`](/docs/reference/cli/t20f-frontier) for those paths.

## Usage

```bash
RUST_LOG=info cargo run --release -p days-legacy --bin days -- <path/to/config.toml>
```

Examples:

```bash
# Minimal example
RUST_LOG=info cargo run --release -p days-legacy --bin days -- configs/simple.toml

# TCP example
RUST_LOG=info cargo run --release -p days-legacy --bin days -- configs/tcp_simple.toml
```

## Arguments

- **`<path/to/config.toml>`** (required): path to the configuration file.

If you do not pass exactly one argument, the binary will `panic!` with a usage message.

## Logging

Days uses `RUST_LOG` for runtime logging.

- Default level if unset: `info`
- Increase verbosity: `RUST_LOG=debug ...`
