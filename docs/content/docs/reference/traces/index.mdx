Days produces two broad kinds of output:

1. **Periodic reports** (e.g., `sources.csv`, `switches.csv`)
2. **Per-transition traces** (`*_events.csv`) used by LeanGuard checkers

This section focuses on per-transition traces and the conventions around them.
