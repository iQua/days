Tests live under `executor/tests/`, `tests/`, `legacy/tests/`, and
`validation/tests/`.

## Default workspace matrix

```bash
cargo test -p days-executor -- --show-output
cargo test -p days --features test -- --show-output
cargo test -p days-legacy --features test -- --show-output
cargo test -p days-validation --features test -- --show-output
```

If `cargo-nextest` is installed, the same package surface can be selected with
`cargo nextest run`; do not use `--all-features` on a machine that cannot build
both device toolchains.

## Planner equality

```bash
# Apple Metal
cargo test -p days --features test,metal-spike \
  --test t20e_planner_bit_equal -- --show-output

# Host-only CUDA planner; no GPU execution
cargo test -p days --features cuda-planner-test \
  --test t20e_planner_bit_equal -- --show-output
```

## T24 byte-identity campaign

The explicit ignored test lowers the committed TCP corpus and compares CPU and
each compiled device backend with the global Scalar oracle:

```bash
cargo test --release -p days-validation --features test \
  --test t24_tcp_corpora \
  full_tcp_corpora_are_byte_identical_across_available_backends \
  -- --ignored --exact --show-output
```

Add `metal-spike` on Apple or `cuda` on a CUDA host to include that device. The
comparison removes device-omitted diagnostic planes, then requires the complete
remaining `RunResult` to be byte-identical.

## E5 fixture gates

Fast fixture/generator checks:

```bash
cargo test -p days --features test --test t21_p12_e5 \
  e5_generator_reproduces_committed_flow_set_fixtures -- --exact --show-output
```

The same test target contains ignored full Scalar, CPU, Metal, and protocol
golden-vector gates. List their exact names before selecting a long campaign:

```bash
cargo test -p days --features test --test t21_p12_e5 -- --list
```

E6 fixtures are not present in this branch and therefore have no runnable E6
command here.
