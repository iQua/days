**Scope: Days AGO and Legacy Days.** The global `[switch]` table configures every egress scheduler created from the topology.

```toml
[switch]
port_rate = 1000000000
capacity = 100
discipline = "FIFO"
drop = "TailDrop"
```

| Field | Type | Requirement |
| --- | --- | --- |
| `port_rate` | number | Required, except on the Spectrum-X topology, which refuses it (its link rates are in `[topology.spectrum_x]`). Bits per second. Exact lowering requires a positive integer bps value representable in `u64`. |
| `capacity` | integer | Required. Packet capacity for configured switch queues. |
| `discipline` | string | Required. Selects the scheduler. |
| `drop` | string | Required. Selects admission or ECN marking. |
| `ecn_threshold` | fraction | Valid only with `drop = "ECN_THRESHOLD"`; must satisfy `0 < value <= 1`. |
| `ecn_by_rate` | array of tables | Days AGO only. One ECN step threshold in packets per egress link rate; replaces `ecn_threshold`. See [ECN thresholds by link rate](#ecn-thresholds-by-link-rate). |
| `weights` | integer array | Used by WFQ, DRR, and WRR. |
| `priorities` | integer array | Used by SP. |
| `vticks` | number array | Used by legacy VirtualClock. |

The strict legacy loader rejects inactive combinations. It permits the historical neutral `weights = [1]` token with FIFO, SP, or VirtualClock, but rejects other inactive weights.

## Scheduling disciplines

| Value | Legacy | Exact Scalar/CPU | Exact Metal/CUDA | Extra field |
| --- | --- | --- | --- | --- |
| `FIFO` | yes | yes | yes | none |
| `SP` | yes | yes | yes | optional `priorities` |
| `WFQ` | yes | yes | yes, with bounded exact rationals | `weights` |
| `DRR` | yes | yes | yes | `weights` |
| `WRR` | yes | yes | yes | `weights` |
| `VirtualClock` | yes | no | no | optional `vticks` |

All classed schedulers map `class_id = flow_id % class_count`.

For SP, `priorities[class_id]` gives the service priority; larger values run first, with FIFO order inside a priority. Missing legacy priorities default to `[1]`. Exact lowering uses the same default.

Legacy requires a non-empty weights array for WFQ, DRR, and WRR. Exact lowering also requires every weight to be positive. It converts DRR weights into 1500-byte-relative quanta. Metal and CUDA reject WFQ checkpoints whose rational numerator or denominator exceeds the device representation; the error reports the field and required bit width.

Legacy VirtualClock defaults missing `vticks` to `[1.0]`. Each tick is seconds per bit. Exact lowering returns:

```text
unsupported scheduler `VirtualClock`; Days executor supports FIFO, SP, WFQ, DRR, and WRR
```

## Drop and ECN policies

| Value | Legacy | Exact Scalar/CPU | Exact Metal/CUDA |
| --- | --- | --- | --- |
| `TailDrop` | yes | yes | yes |
| `ECN_THRESHOLD` | yes | yes | yes |
| `RED` | yes | yes | rejected |
| `RED_ECN` | yes | yes | rejected |

TailDrop drops a packet when admitting it would exceed packet capacity. Capacity `0` means unlimited for TailDrop.

`ECN_THRESHOLD` has a default fraction of `0.8`. Legacy marks an ECN-capable packet and drops a non-ECN-capable packet at the threshold; it marks when post-admission depth is greater than `floor(ecn_threshold * capacity)`. Exact packets carry a lowered `ecn_marked` bit, so the exact scheduler sets that bit at or above `ceil(ecn_threshold * capacity)`. Exact ECN threshold requires positive capacity. Physical capacity overflow drops packets in both runtimes.

Legacy RED and RED_ECN use packet occupancy, thresholds at 70% and 90% of capacity, EWMA weight `2^-9`, and maximum probability `0.8`. RED drops on a congestion action. RED_ECN marks an ECN-capable packet on that action and still drops at physical overflow. Exact RED uses integer deterministic state for byte-identical execution and requires capacity of at least 10 packets.

Metal and CUDA reject lowered RED state before execution:

```text
backend Cuda does not support RED admission; use Scalar or Cpu
```

### ECN thresholds by link rate

**Scope: Days AGO.** A fabric whose links run at different rates can mark at a different depth per rate, as SimAI's `KMIN_MAP` and `KMAX_MAP` rows do. `switch.ecn_by_rate` lists one step threshold, in packets, per egress link rate; every egress link's rate must have a row, and each threshold must lie in `1..=capacity`:

```toml
[switch]
capacity = 3729
discipline = "FIFO"
drop = "ECN_THRESHOLD"
ecn_by_rate = [
    { rate_bps = 100000000000, threshold_packets = 112 },
    { rate_bps = 400000000000, threshold_packets = 223 },
]
```

Each egress queue marks at or above the threshold of its own link rate, as `ecn_threshold` does with one fraction. The table needs `drop = "ECN_THRESHOLD"` and replaces `ecn_threshold`; a scenario that sets both fails to lower ("`switch.ecn_by_rate` replaces `switch.ecn_threshold`"). The AICB adapter derives these rows from `SimAI.conf` at the midpoint of SimAI's marking ramp; see [Workloads](/docs/configuration/workloads).

## ECN-capable transports

Legacy TCP emits `Ect0` only when `[flow.traffic.tcp] ecn = true`. DCQCN data is ECN-capable in both engines. Days AGO TCP rejects ECN and models loss feedback only.

## PFC interaction

PFC monitors per-priority byte occupancy while the scheduler retains packet-capacity admission. Legacy schedulers expose shared queue state to their PFC ingress actors. Exact PFC runs on Scalar, CPU, Metal, and CUDA. See [L2 and PFC](/docs/configuration/l2).
