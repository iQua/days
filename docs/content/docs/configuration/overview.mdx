Days uses one TOML scenario format with two consumers:

- The **legacy actor runtime** validates the complete legacy vocabulary in `legacy/src/config.rs` and runs the scenario with Nexosim.
- The **exact executor** lowers the supported subset in `src/scenario/compile.rs` into a `SimulationImage`, then runs it on Scalar, CPU, Metal, or CUDA.

The legacy CLI takes one configuration path:

```bash
RUST_LOG=info cargo run -p days-legacy --bin days -- configs/simple.toml
```

## Units

| Value | Unit |
| --- | --- |
| Times such as `duration`, `initial_delay`, and `report_interval` | seconds unless the key ends in `_ns` or the page says otherwise |
| `switch.port_rate` | bits per second |
| DCQCN `*_rate_gbps` values | gigabits per second |
| Traffic sizes, packet sizes, and most buffers | bytes |
| Topology and flow identifiers | non-negative integers |

The exact executor represents time in integer nanoseconds. It rejects values that cannot be represented exactly in the field's integer scale.

## Root keys

The strict legacy loader accepts the following root keys. Unknown root keys fail validation.

| Keys | Purpose | Scope |
| --- | --- | --- |
| `seed`, `duration` | Determinism and stop time | Legacy and exact executor |
| `ui_interval` | Progress refresh interval | Legacy |
| `threading`, `num_threads`, `hot_workers`, `concurrency_level` | Nexosim runtime selection | Legacy |
| `time_quantum_ns` | Nexosim time quantization | Legacy; exact executor requires zero or omission |
| `mailbox_capacity` | Actor mailbox capacity | Legacy |
| `log_path`, `csv_logging`, `report_interval` | CSV reports and protocol traces | Legacy logger |
| `legacy_e5_metrics` | Opt-in E5 TCP correctness rows | Legacy |
| `edges`, `hosts`, `topology` | Network graph and host attachments | Legacy and exact executor |
| `switch` | Port rate, queue, scheduler, and AQM policy | Legacy and exact executor, with capability differences |
| `link` | PFC and propagation | Legacy and exact executor, with capability differences |
| `model_host_attachment` | Explicit host injection/delivery stages | Legacy |
| `routing` | Scenario-wide `ShortestPath` or `FatTreeEcmp` | Legacy and exact executor |
| `flow`, `flow_set` | Point-to-point traffic | Legacy and exact executor, with a smaller exact subset |
| `collective`, `collective_set` | Collective traffic | Different algorithm sets in legacy and exact lowering |
| `app_source` | Actor-managed byte buffers for TCP Broadcast/RingAllReduce | Legacy |

See the pages in this section for field-level constraints. A key can belong to the vocabulary and still fail when its value or combination is inactive. The strict loader rejects examples such as `switch.ecn_threshold` without `drop = "ECN_THRESHOLD"`, `[link.pfc]` without `link.mode = "Pfc"`, and `[app_source]` without a supported TCP collective.

## Minimal scenario

This custom topology runs in the legacy actor runtime and lowers into the exact executor:

```toml
seed = 1
duration = 2.0
threading = "single"
csv_logging = false

edges = [[0, 1]]
hosts = [0, 1]

[switch]
port_rate = 1000000000
capacity = 100
discipline = "FIFO"
drop = "TailDrop"

[[flow]]
flow_type = "PacketDistribution"
graph = [[0, 1]]

[flow.traffic]
initial_delay = 0.0
size = 10000
arr_dist = { type = "Uniform", low = 0.001, high = 0.001 }
pkt_size_dist = { type = "DiscreteUniform", low = 512, high = 512 }
```

`threading` and `csv_logging` affect the legacy run. Exact lowering ignores those runtime fields; the caller selects an exact backend through the executor API.

## Cargo features and backend capabilities

Legacy protocol models use Cargo features:

- `flow_type = "DCQCN"` requires `-p days-legacy --features dcqcn`.
- `link.mode = "Pfc"` requires `-p days-legacy --features l2_pfc`.
- LeanGuard event CSVs require `lean` plus the protocol feature where applicable.

Exact Scalar and CPU execute the full lowered mechanism set. Metal and CUDA reject collective generators, DCQCN, PFC, and RED/RED_ECN before execution. They accept deterministic packet traffic, exact TCP Reno/CUBIC, FIFO/SP/WFQ/DRR/WRR, TailDrop, and ECN threshold subject to device capacity checks. The error names the unsupported mechanism and directs you to Scalar or CPU.
