**Scope: Days AGO.** Days AGO returns structured state and observations to its caller and writes no CSV files itself. The legacy CSV logger is described in [Legacy logging and reports](/docs/legacy/components/logging).

## Result planes

Every backend returns a normalized `RunResult` with final host state, switch state, constant-space `RunSummary` counters, resident packets needed to resume, canonical pending events, and the requested packet observations.

`ObservationMode::Summary` keeps aggregate counters without full per-packet history. `ObservationMode::Full` retains departures and arrivals. In full mode, Scalar and CPU also return `DiagnosticPlanes` with the exact TCP, AQM, rate, PFC, DRR, WRR, DCQCN, and collective transitions. Metal and CUDA return complete state and measurement planes but set `diagnostics` to `None`.

## Certificate serializers

The executor library exposes CSV serializers for TCP, AQM, rate, PFC, DRR, WRR, DCQCN, and collective transition records (`executor/src/tcp_trace.rs`, `executor/src/aqm_trace.rs`, and `executor/src/mechanism_trace.rs`). Callers choose where to write those strings. The LeanGuard checkers for these families are listed in [LeanGuard (Use Guide)](/docs/verification/leanguard).

The [`days` CLI](/docs/reference/cli) prints summary records and a complete-state fingerprint; it does not write transition CSVs.
