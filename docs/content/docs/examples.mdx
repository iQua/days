Days supports two “example styles”:

1. **Config-driven simulations** (`configs/*.toml`) run via the legacy CLI (`cargo run -p days-legacy --bin days -- <config>`).
2. **Rust examples** (`legacy/examples/*.rs`) run via `cargo run -p days-legacy --example <name>`.

## Config examples

Run a config from the repo root:

```bash
RUST_LOG=info cargo run -p days-legacy --bin days -- configs/simple.toml
```

Measure wall-clock time without logs:

```bash
time cargo run -p days-legacy --bin days -- configs/simple.toml
```

DCQCN example (requires `dcqcn` and typically `l2_pfc`):

```bash
RUST_LOG=info cargo run -p days-legacy --features dcqcn,l2_pfc --bin days -- configs/dcqcn_simple.toml
```

## Rust examples

List available example binaries:

```bash
ls legacy/examples
```

Run one:

```bash
RUST_LOG=info cargo run -p days-legacy --example basic
```

The repo currently includes examples such as `basic`, `switch`, `wire`, `tcp`, and `ecn` (names match the `.rs` filenames in `legacy/examples/`).
