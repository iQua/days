This page maps the main subsystems of Days to the source tree, to make it easier to navigate the codebase.

## Entry points

- `legacy/src/main.rs`: legacy CLI entry point (expects a TOML config path).
- `src/lib.rs`: shared/current library root; `legacy/src/lib.rs` owns legacy IDs, seed state, and simulation entry points.

## Topology construction and execution

- `src/topos/build.rs`: parses topology settings and builds a `petgraph` `UnGraph` (FatTree, Torus, or custom edges/hosts).
- `legacy/src/topos/topo.rs`: the legacy orchestration layer:
  - parses runtime config (threads, duration, mailbox capacity),
  - instantiates switches, schedulers, sources/sinks,
  - computes routes and installs switch forwarding tables,
  - runs the simulation and flushes logs,
  - conditionally wires the PFC link pipeline when enabled.

## Switching and forwarding

- `legacy/src/switches/mod.rs`: scheduler selection reexports.
- `legacy/src/switches/switch.rs`: `PacketSwitch` (demultiplexes packets using `fib` / `r_fib` and forwards via `Output<Packet>` ports).

## Queueing and scheduling (per edge)

- `legacy/src/schedulers/mod.rs`: `ReportStatistics` trait and shared report reexports.
- `legacy/src/schedulers/drop.rs`: drop/mark policies (`TailDrop`, `RED`, `RED_ECN`, `ECN_THRESHOLD`).
- `legacy/src/schedulers/state.rs`: `QueueState` (shared occupancy tracking, used by PFC).
- `legacy/src/schedulers/port.rs`: FIFO scheduler (`Port`).
- `legacy/src/schedulers/drr.rs`: Deficit Round Robin.
- `legacy/src/schedulers/wrr.rs`: Weighted Round Robin.
- `legacy/src/schedulers/wfq.rs`: Weighted Fair Queueing.
- `legacy/src/schedulers/sp.rs`: Static Priority.
- `legacy/src/schedulers/vc.rs`: Virtual Clock.

## Flows (sources, sinks, routing, collectives)

- `legacy/src/flows/mod.rs`: traffic types and legacy process-model exports.
- `legacy/src/flows/packet.rs`: `Packet`, ECN field, TCP ACK metadata, control packet markers.
- `legacy/src/flows/flow.rs`: `Flow` config parsing and path computation.
- `src/topos/route.rs`: shared routing implementations (ShortestPath, ECMP, PathFromConfig).
- `legacy/src/flows/source.rs`: `PacketSource` enum (dispatch wrapper for different sources).
- `legacy/src/flows/dist_source.rs`: packet distribution source.
- `legacy/src/flows/tcp_source.rs`: TCP source (Reno/CUBIC/BBR congestion control, optional app-backed data).
- `legacy/src/flows/sink.rs`: `PacketSink` enum (dispatch wrapper for different sinks).
- `legacy/src/flows/basic_sink.rs`: basic sink (stats + completion notification).
- `legacy/src/flows/tcp_sink.rs`: TCP sink (ACK generation, ECN echo).
- `legacy/src/flows/cc.rs`: congestion control trait + algorithm selection.
- `legacy/src/flows/reno.rs`, `legacy/src/flows/cubic.rs`, `legacy/src/flows/bbr.rs`: congestion control algorithm implementations.
- `legacy/src/flows/collective.rs`: collective parsing and endpoint generation.
- `legacy/src/flows/app_source.rs`: application-level byte buffers for TCP collectives (actor-based).
- `legacy/src/flows/wire.rs`: optional propagation-delay element (not part of the default topology pipeline).
- `legacy/src/flows/dcqcn_source.rs`, `legacy/src/flows/dcqcn_sink.rs`: DCQCN models (feature `dcqcn`).

## Optional L2 / PFC

- `legacy/src/l2/frame.rs`: `LinkFrame` (data + optional PFC frames).
- `legacy/src/l2/link.rs`: `Link` serializer (transmits frames at a configured rate).
- `legacy/src/l2/pfc.rs`: `PfcIngressPort` + `PfcEgressGate` and reporting.

## Logging, UI, and tracing

- `src/utils/logger.rs`: CSV logger singleton, report buffering, optional DCQCN event traces.
- `legacy/src/utils/ui.rs`: progress bar UI model.
- `src/utils/tracing.rs`: concurrency tracking layer and sampler model.

## Tests and examples

- `tests/`, `legacy/tests/`, and `validation/tests/`: current, legacy, and cross-engine integration tests.
- `legacy/examples/`: runnable Rust examples (`cargo run -p days-legacy --example <name>`).
